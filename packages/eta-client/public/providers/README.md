# Provider icons

`kimi.svg` is the monochrome Kimi icon from [LobeHub Icons](https://lobehub.com/zh/icons), downloaded from [lobehub/lobe-icons](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/kimi.svg).

The SVG is bundled locally. The settings stylesheet renders it black in light mode and inverts it to white in dark mode. The upstream MIT license is included in `LOBE-ICONS-LICENSE`.

`deepseek.svg` is the monochrome DeepSeek icon from the same collection, downloaded from [the upstream SVG](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/deepseek.svg), under the included MIT license.
