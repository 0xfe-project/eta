# 待处理

右侧栏的“待处理”标签页（和全窗口的“待处理”页）列出等用户处理的事，所有智能体的都在里面。它是从现有数据派生的列表，不新增状态（#103）：

- 任务：指派给你、待验收（`in_review`）、受阻（`blocked`）、最近一次远程运行失败、或有 AXP 智能体请求的运行在等你确认（#99），已完成和已取消的除外；
- 定时任务：有你还没看过的报告或失败的运行。`routine_run.seen_at` 记录你看过的时间（迁移 `00003`，之前结束的运行算作看过），打开一个定时任务时（`POST /routines/{id}/seen`）它已结束的运行都算看过；列表接口的摘要带 `unseen_reports`、`unseen_failures`。

侧栏、右侧栏“待处理”和手机上“工作区”按钮的数字是两类加起来的总数，概览里的“待处理”也是它；任务页的数字仍是待验收的任务数。

聊天智能体的工具不再请用户确认操作：Codex 以 `never` 审批运行（见[聊天与运行时架构](chat-runtime.md#runtime)）。有风险的能力应该放在容器外、经网关访问，由插件的服务自己决定能做什么。
